## 💭 Engineering Philosophy

제가 만든 도구들은 플랫폼과 무관하게 공통적으로 **"반복되는 수작업을 자동화 도구로 대체하는 것"** 을 목표로 합니다.
대규모 엔터프라이즈 SaaS 플랫폼 위에서는 여러 인스턴스에 걸친 계정 생성/비활성화, 구축 비용 산정, 보안 취약점 대응 항목 생성처럼 매번 손으로 반복하던 작업을 스크립트와 저코드로 자동화해왔고, 독립적으로 진행한 풀스택 프로젝트에서도 강사 배정과 정산처럼 사람이 일일이 처리하던 업무를 시스템으로 옮기는 데 집중했습니다.
사용하는 스택이 무엇이든, 제 개발의 출발점은 항상 "누군가 매번 손으로 하던 일을 도구가 대신하게 만드는 것"입니다.
